# Керамика

Вымышленная керамическая мастерская. Посетитель выбирает занятие по времени и наличию мест; постоянный посетитель проверяет свои записи.

1. Расписание /schedule: три занятия, фильтр мест, состояния загрузки/пустоты/ошибки/успеха.
2. Мои записи /bookings: две записи с текстовыми статусами. В учебной копии этот экран создаётся на практике 6.

Данные фиксированы в файлах, настоящего сервера данных нет. Вход, создание/отмена записи, платежи и хранение изменений не входят в проект. Галочка фильтра сбрасывается при обновлении, данные восстанавливаются из файла. Параметр state — учебный переключатель, а не результат сетевого запроса.

Источник интерфейса: https://www.figma.com/design/LfGN425jPYlojWrNXMsVWt
