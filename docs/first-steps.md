# Первый раз открываем код

Это обычная папка с файлами. Работайте в распакованной **учебной копии**, не внутри ZIP. Отдельно открываем редактор (меняем файлы) и браузер (видим результат). Опыт программирования не требуется.

## 1. Подготовьте программы до пары

Установите [Node.js LTS](https://nodejs.org/en/download), [Visual Studio Code](https://code.visualstudio.com/) и [Git](https://git-scm.com/downloads). Для нового компьютера выбирайте Node.js 24 LTS или актуальный LTS, не Alpha/Current. Минимум для этой заготовки — Node 20.19; Node 20 уже не рекомендуется для новой установки. После установки закройте и откройте редактор. Интернет нужен для первой установки пакетов, затем приложение работает с локальными данными.

Если нет прав на установку, обратитесь к преподавателю до занятия. Аккаунты, API-ключи, Docker и база данных не нужны.

## 2. Откройте папку

Распакуйте keramika-classroom.zip в понятное место, например Documents/ITMO. В VS Code: File → Open Folder («Файл → Открыть папку»), выберите папку **glina-classroom**, в которой лежит package.json. Слева видны app, components, lib, README.md. Если видна только ещё одна папка glina-classroom, откройте её.

Если редактор спрашивает доверие, подтвердите только для своей копии, полученной от преподавателя. Затем Terminal → New Terminal («Терминал → Создать терминал»). Терминал — поле ввода команд внизу редактора. Печатайте команду, нажимайте Enter, ждите результата. Значки ``` и слова bash/powershell копировать не нужно.

Проверьте по одной:

```text
node --version
npm --version
git --version
```

Должны появиться номера версий. Если Windows сообщает, что npm.ps1 заблокирован, используйте **npm.cmd** вместо npm во всех командах ниже. Политику безопасности PowerShell менять не нужно. Для npx аналогично npx.cmd.

## 3. Первый запуск

В терминале этой папки:

```text
npm ci
```

Команда загружает версии библиотек из package-lock.json. Дождитесь окончания и новой строки ввода; это может занять несколько минут. Не запускайте следующую команду после красной ошибки.

```text
npm run dev
```

Дождитесь Ready. Откройте в браузере **http://127.0.0.1:3000/schedule**. Должны быть три карточки и галочка «Только со свободными местами». После её включения останутся две. В учебной копии цвет пока нейтральный — палитру «Керамики» перенесём на практике 4.

Терминал остаётся занят: приложение работает, это нормально. Не закрывайте его во время изменений. Если Next выбрал другой порт, например 3001, используйте адрес из строки Local и заменяйте 3000 в примерах. Остановка: нажмите Ctrl+C в терминале (на macOS тоже Ctrl+C); если Windows спрашивает завершение пакетного файла, ответьте Y. Повторный запуск: npm run dev, заново npm ci не нужен, пока зависимости не менялись.

## 4. Первая правка — пять минут

1. Слева откройте lib → workshops.ts. Или Ctrl+P (на Mac Cmd+P), введите lib/workshops.ts и Enter.
2. Найдите **Кружка ручной лепки**. Предскажите, что изменится одна карточка.
3. Замените только эти слова внутри кавычек на **Моя первая кружка**. Кавычки, запятые, скобки оставьте.
4. Ctrl+S / Cmd+S сохраняет файл. Переключитесь в браузер: название должно обновиться. Если нет — обновите страницу.
5. Верните исходное название и сохраните. Это проба. Отдельную ручную правку для КТ сделаете позже.

Если появилась ошибка, отмените только своё последнее действие: Ctrl+Z / Cmd+Z, затем сохраните. Если не помогло, покажите преподавателю сообщение и последнее действие. Не удаляйте папки и не нажимайте «Discard all changes».

## 5. Что лежит в папках

| Файл | Что меняем |
|---|---|
| lib/workshops.ts | Название, время и места конкретного занятия; рядом готовый переключатель state |
| components/workshop-card.tsx | Общий вид всех карточек |
| components/schedule-list.tsx | Фильтр и промежутки между карточками |
| app/globals.css | Цвета, размеры текста, радиусы |
| components/ui/button.tsx | Готовая кнопка; на первой практике не переписываем |
| components/state-view.tsx | Готовые загрузка, пустота, ошибка |
| app/schedule/page.tsx | Соединяет адрес и экран расписания |
| PRODUCT.md | Что делает продукт |
| DESIGN.example.md | Образец правил; свой DESIGN.md создадим на практике 5 |
| DECISIONS.md | Почему приняли решение |

В эталоне дополнительно app/bookings/page.tsx и lib/bookings.ts. В учебной копии их пока нет: это задание практики 6. Файлы node_modules и .next создают инструменты, их не редактируем и не отправляем преподавателю.

## 6. Сохранить версию в Git — один раз вместе с преподавателем

Сохранение Ctrl+S записывает файл. Коммит сохраняет понятную точку истории проекта. Перед началом работы открыть Source Control («Управление версиями», Ctrl+Shift+G). Если репозитория ещё нет, нажать Initialize Repository именно для папки glina-classroom. .gitignore уже исключает node_modules, .next и служебные файлы. Убедитесь, что нет .env, ключей и чужих файлов в списке.

Для первоначальной точки выберите только файлы заготовки кнопкой +, напишите `chore: start glina exercises`, нажмите Commit. Publish/Sync для этого не нужен. Если Git просит имя/email, преподаватель поможет задать их для этого проекта; не вводите пароль или токен в код.

При следующих правках нажмите на файл в Source Control: красные строки удалены, зелёные добавлены. Это diff — сравнение «до / после». Прочитайте изменённые строки, выберите нужный файл через +, напишите, что и зачем поменяли, Commit. Ручную правку сохраняйте отдельно. Если список неожиданно большой — остановитесь, не выбирайте всё подряд.

## Если что-то не работает

| Сообщение / ситуация | Следующий шаг |
|---|---|
| node/npm не найден | Перезапустить редактор после установки; проверить Node с преподавателем |
| ENOENT, package.json не найден | Открыта не та папка; найдите папку с package.json и создайте в ней терминал |
| npm ci завершился ошибкой | Скопировать конец сообщения и показать преподавателю; не удалять lockfile и не обновлять всё |
| npm warn deprecated eslint, но установка завершилась | В заготовке закреплена версия, совместимая с инструментами Next.js. Это предупреждение, не ошибка запуска. Не запускайте обновление пакетов или npm audit fix самостоятельно |
| Порт занят | Остановить свою предыдущую сессию Ctrl+C либо взять адрес Local нового запуска |
| Изменение не видно | Сохранить файл, проверить адрес Local, обновить браузер; не открывать HTML-файл двойным кликом |
| /bookings показывает «страницы пока нет» | До практики 6 в учебной копии это ожидаемо |
| Адрес из README не открывается у соседа | 127.0.0.1 — ваш компьютер. Передайте управление своим браузером, не ссылку на чужую машину |
